Glosario: Orientación y Python

Diez conceptos esenciales con definiciones breves y contextualizadas.

10 términos

Unidad de análisis

Entidad elemental sobre la que se mide, predice o decide.

Variable

Atributo observado o calculado para cada unidad de análisis.

Métrica de éxito

Medida acordada para evaluar si una intervención crea valor.

Notebook

Documento ejecutable que combina texto, código y resultados.

DataFrame

Estructura tabular etiquetada provista por pandas.

Vectorización

Operación sobre colecciones completas sin bucles explícitos.

Semilla aleatoria

Valor que permite repetir una secuencia pseudoaleatoria.

Dependencia

Biblioteca externa requerida para ejecutar un proyecto.

Control de versiones

Registro trazable de cambios en archivos y código.

Reproducibilidad

Capacidad de regenerar un resultado con los mismos insumos.
