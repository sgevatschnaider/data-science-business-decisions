Glosario: Transformación y pipelines

Diez conceptos esenciales con definiciones breves y contextualizadas.

10 términos

Transformación logarítmica

Cambio de escala que comprime valores altos y requiere dominio válido.

Estandarización

Centrado por media y escalado por desvío estándar.

Min-max

Reexpresión lineal dentro de un intervalo, habitualmente de cero a uno.

One-hot encoding

Representación binaria separada para cada categoría nominal.

Codificación ordinal

Asignación numérica que conserva un orden real entre categorías.

Feature engineering

Construcción de variables útiles a partir de datos disponibles.

Interacción

Variable que representa el efecto conjunto de dos o más factores.

Pipeline

Secuencia encapsulada de transformaciones y estimación.

ColumnTransformer

Aplicador de transformaciones diferentes por grupos de columnas.

Leakage temporal

Uso de información futura para construir una variable o ajustar un proceso.
