Cómo estudiar estas clases

  1. Leé las diapositivas y explicá los conceptos con tus palabras.
  2. Identificá la hipótesis o condición que sostiene cada procedimiento.
  3. Repetí el diagnóstico con las simulaciones interactivas.
  4. Evaluá el riesgo de fuga de información y de sesgo.
  5. Defendé una decisión con un ejemplo realista.
