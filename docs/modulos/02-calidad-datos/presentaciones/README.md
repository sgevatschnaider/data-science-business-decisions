# Módulo 02 · Presentaciones independientes de Google Drive

Material elaborado por el profesor Sergio Gevatschnaider para **Ciencia de Datos para Decisiones de Negocio**.

Las tres presentaciones originales de Google Slides se exportaron a PDF sin alterar sus archivos fuente. Estos PDF están **alojados directamente en GitHub**: los alumnos pueden abrirlos en el navegador, descargarlos o consultarlos mediante visores interactivos **sin tener que pedir acceso a Google Drive**.

Los visores ofrecen avanzar y retroceder, seleccionar páginas con un control deslizante, consultar miniaturas, reproducción automática, pantalla completa, navegación por teclado y descarga del PDF. Si un navegador bloquea el servicio externo de renderizado, pueden abrirse directamente los PDF locales del repositorio.

Los archivos **editables originales** permanecen sin cambios en Google Drive. Se recomienda consultar la versión PDF como referencia visual fiel de las presentaciones.

## Comprobaciones

Se verificó cada PDF: 10 páginas, formato 16:9, documento legible y texto extraíble. Los tres archivos se validan en el flujo de control del repositorio con comprobación de cabecera PDF, tamaño, existencia y rutas desde los visores.
