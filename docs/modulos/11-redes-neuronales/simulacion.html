RNN paso a paso: cómo una secuencia se convierte en memoria

Recorré cada instante, observá la actualización del estado oculto y comprobá cómo los pesos determinan cuánto importa la entrada actual y cuánto permanece del pasado.

Secuencia temporal Estado oculto Recurrencia Activación

Modelo mínimo

Una misma transformación repetida en el tiempo

La RNN procesa una observación por vez. En cada paso combina el dato presente con una memoria resumida del paso anterior.

Actualización recurrente ht = φ(Wxxt + Whht−1 + b) La función φ puede ser tanh, sigmoide o ReLU.
xt

Entrada actual

Representa el dato que llega en el instante t: una venta, una palabra, una señal o un evento.

ht−1

Memoria previa

Resume el contexto acumulado. No almacena literalmente toda la secuencia: conserva una representación comprimida.

ht

Nuevo estado

Integra presente y pasado. Se convierte en la memoria que recibirá el siguiente paso temporal.

01

Leé la secuencia

Elegí un caso y avanzá paso a paso. El elemento activo es la observación que la red está procesando.

02

Separá las contribuciones

Compará Wxxt con Whht−1. Así distinguís cuánto proviene del presente y cuánto de la memoria.

03

Diagnosticá la dinámica

Probá memoria corta, equilibrada, persistente y saturada. Observá cuándo la señal se pierde, oscila o deja de responder.

Preguntas para interpretar, no solo mirar

  1. ¿Qué cambia cuando Wh se acerca a cero?
  2. ¿Puede una entrada nueva corregir una memoria previa intensa?
  3. ¿Qué diferencia observás entre tanh, sigmoide y ReLU?
  4. ¿Por qué una RNN simple puede tener dificultades para conservar dependencias lejanas?
