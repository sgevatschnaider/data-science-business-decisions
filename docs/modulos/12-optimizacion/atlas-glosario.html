Ejemplos que conectan el material del curso

Se conservan los ejemplos Base/Plus y Comidas Z del material original, y se incorpora la fábrica A/B como caso transversal de las presentaciones y del simulador.

01 · Base y Plus — PL continua

max Z = 3X₁ + 5X₂

X₁ ≤ 4
2X₂ ≤ 12
3X₁ + 2X₂ ≤ 18
X₁, X₂ ≥ 0

El modelo compara dos productos bajo tres límites. Las restricciones se convierten en fronteras y el óptimo se localiza en un vértice.

Óptimo del material: X₁=2, X₂=6, Z=36.

02 · Fábrica inteligente — PL continua

max Z = 40A + 30B

2A + B ≤ 100
A + 2B ≤ 80
A, B ≥ 0

Ejemplo didáctico nuevo para explorar variables, recursos, región factible, Simplex y precios sombra.

Óptimo: A=40, B=20, Z=$2.200.

03 · Comidas Z — PLE

max Z = 12xₑ + 20x_f

0,2xₑ + 0,6x_f ≤ 2,7
3xₑ + x_f ≤ 19
x_f ≥ 2; xₑ,x_f ∈ ℤ₊

La decisión es cuántos locales Express y Full abrir. El número de locales no admite fracciones.

Solución entera del material: xₑ=4, x_f=3, Z=108.

Importante: los resultados de estos tres ejemplos pertenecen a modelos diferentes. No mezclar el óptimo Z=36 de Base/Plus con el Z=$2.200 de la fábrica A/B ni con el Z=108 de Comidas Z.
