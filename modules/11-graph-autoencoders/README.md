# Módulo 11.2: Graph Autoencoders

Curso Ciencia de Datos para Decisiones de Negocio · Sergio Gevatschnaider.

## Pregunta de decisión

¿Puede un modelo de grafos aprender vínculos útiles sin confundirse con evidencia causal o dinámica evolutiva?

## Ampliación académica: 72 diapositivas HTML y 3 laboratorios avanzados

[**Abrir masterclass ampliada · 11.2**](https://sgevatschnaider.github.io/data-science-business-decisions/modulos/11-graph-autoencoders/masterclass.html). Contiene GCN normalizado, decoder y BCE, split de enlaces sin leakage, métricas AP/AUC, redes multinivel y límites de la Reina Roja. Tres laboratorios nuevos permiten modificar la capa de grafo, inspeccionar probabilidad y BCE y visualizar por qué un enlace retenido no debe entrar al encoder.

Los PPTX/PDF previos son **presentaciones clásicas**, no exportaciones del nuevo visor de 72 diapositivas HTML. El notebook amplía el ejemplo de seis actores a un grafo sintético de 90 nodos con validación retenida y baseline topológico.
