Frontera de decisión 2D

Modifica \(β_0\), \(β_1\), \(β_2\) y el threshold para observar cómo cambia la frontera entre las clases. El fondo representa un campo continuo de probabilidades: la frontera no crea la probabilidad, simplemente marca dónde la regla de decisión cambia de clase.

z = β₀ + β₁x₁ + β₂x₂Con dos variables, cada punto del plano recibe un score.
p = σ(z)El score se transforma en probabilidad mediante la sigmoide.
Frontera: β₀ + β₁x₁ + β₂x₂ = logit(c)Si c = 0.5, logit(c)=0 y aparece la forma clásica z=0.

Qué observar

Ideas clave
1 · La frontera es una isoprobabilidadTodos los puntos sobre la línea tienen exactamente la misma probabilidad: p = c.
2 · El plano contiene probabilidades, no solo clasesDos puntos de la misma clase predicha pueden tener riesgos muy diferentes, por ejemplo p=0.52 y p=0.95.
3 · Cambiar el threshold no cambia βLa regla operativa se mueve sobre el mismo campo probabilístico; el modelo subyacente permanece igual.
